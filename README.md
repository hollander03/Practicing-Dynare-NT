Sections 2–3 cover stochastic growth and estimation. Sections 4–5 cover deterministic fiscal transitions and elastic labour. Original 2025 code revisions are preserved separately; unmatched models are archived with explanations. Section 6 remains a placeholder for the separate NT-DSGE model.

This pass checks equations, code execution and annotations. Historical figures, tables, posterior summaries and textbook replication are reserved for a later explicit comparison. No visual checks were requested or performed.
