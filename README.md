# Practicing Dynare: fiscal-policy workbook

The participant workbook is [practice_dynare_FP.tex](practice_dynare_FP.tex).

- [Model files and run instructions](Code/README.md)
- [Participant command notes](notes/README.md)
- [Factor prices, returns and bond prices](notes/q_and_auxiliaries.md)
- [Figure map](notes/figure_map.md)

Sections 2–3 introduce stochastic growth, simulation and estimation. Sections 4–5 study fiscal transitions, anticipated policy and labour supply. Each model has local definitions, calibration values and matching code.

The figures in `figures/` come from the saved numerical results in `Code/full_replications/results_snapshot`. They can be redrawn without solving the models using `tools/redraw_saved_figures.m`. Figures not used by the current workbook are stored in `figures/archive/`.

The [Overleaf project](https://www.overleaf.com/read/cbpwghwvmyck#f1a82c) is linked to this GitHub repository. Its main document is `practice_dynare_FP.tex`.
