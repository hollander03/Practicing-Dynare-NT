Introduction
• In Ljungqvist and Sargent (2004) (LS), Hall (1971)’s nonstochastic
growth model is augmented with a fiscal block.
• The distorting taxes prevents competitive equilibrium allocation. To
solve, LS uses a numerical method called a shooting algorithm.
• Solution shows how current endogenous variables respond to paths of
future exogenous variables, which is useful from a planner’s
perspective.
• In this exercise, the code from Practicing Dynare is:
• Amended the example code to run in Dynare 6.4.
• Replicated the policy shocks.

Challenges
• Old code uses simul, deprecated in Dynare 6.4; new code uses
perfect foresight setup and perfect foresight solver for
compatibility.
• Old code lacks shocks; block, causing errors; new code adds
shocks; for correct exogenous variable specification.
• Old code uses y , ex , ys0 , ys ; new code uses oo .endo simul,
oo .exo simul, and explicitly saves steady states.
• Old code relies on undefined var index; new code uses explicit indices
(1 for c, 2 for k).
• New code improves syntax (e.g., semicolons, line breaks) for
readability and error prevention.
• Both replicate the different figures, showing responses to a different
fiscal variables at t = 10.
